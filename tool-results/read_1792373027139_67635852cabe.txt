   723→  1256→### Bullet summary
   724→  1257→
   725→  1258→**Constants / data**
   726→  1259→- `WALLPAPER_URL` — Unsplash photo URL (also referenced in the `.wallpaper-img` CSS); preloaded by an `Image()` so the `.loaded` class can fade it in.
   727→  1260→- `DEMO` — `{ password:"demo", pin:"1234", patternMinLen:4 }` accepted credentials / pattern minimum.
   728→  1261→- `SESSIONS` — Array of 6 desktop sessions (`hyprland`, `kde`, `gnome`, `sway`, `xfce`, `custom`); each carries `id`, `name`, `desc`, and an inline SVG `logo` used in the session popover.
   729→  1262→- `USERS` — Array of 6 demo users (`Aria Voss`, `Kenji Sato`, `Mira Sol`, `Devon Hart`, `Yuki Tanaka`, `Sage Lin`) with pravatar.cc avatars and a per-user `auth` strategy (`password`, `pin`, `pattern`, `question`, or `multi-step`), optional `pw`, `requiresUsername`, `question`/`answer`, or a `steps[]` array.
   730→  1263→
   731→  1264→**State variables (single `state` object)**
   732→  1265→- `userIndex`, `method` (current auth method), `authStatus` (`idle|loading|success`).
   733→  1266→- `multiStep` = `{ active, current, total }` for users with chained steps.
   734→  1267→- `session`, `theme` (`dark|light`), `openPop` (which popover is open), `drawerOpen`, `powerAction`.
   735→  1268→- `net` = `{ name, online }`, `battery` = `{ level, charging }`, `volume` = `{ level, muted }`.
   736→  1269→- `pin` (entered PIN string), `pattern` (selected dot-index array), `patternDrawing` (boolean).
   737→  1270→
   738→  1271→**Helpers**
   739→  1272→- `$` / `$$` — scoped `querySelector` / `Array.from(querySelectorAll)`.
   740→  1273→- `user()` / `session()` — current user / session object lookups.
   741→  1274→- `refreshIcons()` — re-runs `lucide.createIcons()` after dynamic `<i data-lucide>` insertions.
   742→  1275→- `swapIcon(el, name)` — Replaces an existing icon element (svg or `[data-lucide]`) with a new `<i data-lucide="…">`, preserving non-`lucide` classes, then `refreshIcons()`.
   743→  1276→
   744→  1277→**Render functions**
   745→  1278→- `renderIdentity()` — Sets the avatar `src` (with `onerror` fallback gradient), `#userName`, `#userHandle`.
   746→  1279→- `renderSession()` — Updates `#sessionVal` and toggles `.selected` + check opacity on the session list items.
   747→  1280→- `renderVolume()` — Picks `volume-x`/`volume-1`/`volume-2` icon, swaps it on both `#volBtn` and `#volToggle`, updates `#volText`/`#volTip`/`#volSlider`/`#volValue`, toggles `.muted` on the toggle.
   748→  1281→- `renderBattery()` — Sets `#batFill` width, `#batText`, and `#batTip` (charging vs remaining).
   749→  1282→- `renderNetwork()` — Sets `#netText` to the SSID.
   750→  1283→- `renderAll()` — Calls all five renderers in order.
   751→  1284→
   752→  1285→**Auth flow control**
   753→  1286→- `updateAuthChrome()` — Detects `multi-step` users, hides/shows method tabs vs step indicator, toggles the username sub-input (`requiresUsername`), swaps the password field's lead icon (`user-round` vs `lock`), then `renderStep()` or `setMethod(u.auth)`, then `updateDemoHints()`.
   754→  1287→- `setMethod(m)` — Sets `state.method`, toggles `.active` on the matching tab and panel, calls `clearErrors()`, and (for pattern) schedules `buildPattern()` after 50 ms.
