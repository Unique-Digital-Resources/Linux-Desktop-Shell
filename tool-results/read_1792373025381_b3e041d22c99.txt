  1256→### Bullet summary
  1257→
  1258→**Constants / data**
  1259→- `WALLPAPER_URL` — Unsplash photo URL (also referenced in the `.wallpaper-img` CSS); preloaded by an `Image()` so the `.loaded` class can fade it in.
  1260→- `DEMO` — `{ password:"demo", pin:"1234", patternMinLen:4 }` accepted credentials / pattern minimum.
  1261→- `SESSIONS` — Array of 6 desktop sessions (`hyprland`, `kde`, `gnome`, `sway`, `xfce`, `custom`); each carries `id`, `name`, `desc`, and an inline SVG `logo` used in the session popover.
  1262→- `USERS` — Array of 6 demo users (`Aria Voss`, `Kenji Sato`, `Mira Sol`, `Devon Hart`, `Yuki Tanaka`, `Sage Lin`) with pravatar.cc avatars and a per-user `auth` strategy (`password`, `pin`, `pattern`, `question`, or `multi-step`), optional `pw`, `requiresUsername`, `question`/`answer`, or a `steps[]` array.
  1263→
  1264→**State variables (single `state` object)**
  1265→- `userIndex`, `method` (current auth method), `authStatus` (`idle|loading|success`).
  1266→- `multiStep` = `{ active, current, total }` for users with chained steps.
  1267→- `session`, `theme` (`dark|light`), `openPop` (which popover is open), `drawerOpen`, `powerAction`.
  1268→- `net` = `{ name, online }`, `battery` = `{ level, charging }`, `volume` = `{ level, muted }`.
  1269→- `pin` (entered PIN string), `pattern` (selected dot-index array), `patternDrawing` (boolean).
  1270→
  1271→**Helpers**
  1272→- `$` / `$$` — scoped `querySelector` / `Array.from(querySelectorAll)`.
  1273→- `user()` / `session()` — current user / session object lookups.
  1274→- `refreshIcons()` — re-runs `lucide.createIcons()` after dynamic `<i data-lucide>` insertions.
  1275→- `swapIcon(el, name)` — Replaces an existing icon element (svg or `[data-lucide]`) with a new `<i data-lucide="…">`, preserving non-`lucide` classes, then `refreshIcons()`.
  1276→
  1277→**Render functions**
  1278→- `renderIdentity()` — Sets the avatar `src` (with `onerror` fallback gradient), `#userName`, `#userHandle`.
  1279→- `renderSession()` — Updates `#sessionVal` and toggles `.selected` + check opacity on the session list items.
  1280→- `renderVolume()` — Picks `volume-x`/`volume-1`/`volume-2` icon, swaps it on both `#volBtn` and `#volToggle`, updates `#volText`/`#volTip`/`#volSlider`/`#volValue`, toggles `.muted` on the toggle.
  1281→- `renderBattery()` — Sets `#batFill` width, `#batText`, and `#batTip` (charging vs remaining).
  1282→- `renderNetwork()` — Sets `#netText` to the SSID.
  1283→- `renderAll()` — Calls all five renderers in order.
  1284→
  1285→**Auth flow control**
  1286→- `updateAuthChrome()` — Detects `multi-step` users, hides/shows method tabs vs step indicator, toggles the username sub-input (`requiresUsername`), swaps the password field's lead icon (`user-round` vs `lock`), then `renderStep()` or `setMethod(u.auth)`, then `updateDemoHints()`.
  1287→- `setMethod(m)` — Sets `state.method`, toggles `.active` on the matching tab and panel, calls `clearErrors()`, and (for pattern) schedules `buildPattern()` after 50 ms.
  1288→- `clearErrors()` — Strips `.error`/`.show` from every field, error message, and pin dots.
  1289→- `stepLabel(type)` — Maps a step type to a display label.
  1290→- `renderStep()` — Updates `#stepLabel` ("Step X of Y · Type") and rebuilds `#stepDots` (active + completed dots), then `setMethod(step.type)` + `updateDemoHints()`.
  1291→- `advanceStep()` — Resets the just-completed step's input (password/PIN/pattern/question), increments `multiStep.current`, and `renderStep()`.
  1292→- `onAuthSuccess()` — Either `advanceStep()` (after a 450 ms delay) when more steps remain, or `showSuccess()` for the final success.
  1293→- `updateDemoHints()` — Writes the demo hint for every method (`demo: …`), and either shows the user's `question`/`answer` in `#questionText`/`#qHint` or a "no question set" fallback.
  1294→- `setBtnLoading(btn, on)` — Toggles `.loading` + `disabled` on a primary button and sets `state.authStatus` accordingly.
  1295→- `showSuccess()` — Fills `#successTitle`/`#successSub`/`#successIcon` and adds `.show` to the success overlay.
  1296→- `returnToGreeter()` — Removes `.show` from both overlays, resets `authStatus`/`multiStep.current`, re-renders the current step if multi-step, clears every input + pin + pattern + errors.
  1297→- `flashError(fieldEl, msgEl, msg)` — Adds `.error` to the field, sets the message text + `.show`, then strips `.error` after 420 ms.
  1298→
  1299→**Per-method handlers**
  1300→- `submitPassword(e)` — Validates username (if required) and password presence, sets the submit button loading, then after 850 ms compares against the user's `pw` (or the step's `pw` if multi-step) and either calls `onAuthSuccess()` or `flashError()`.
  1301→- `renderPin()` — Toggles `.filled` on the four pin dots based on `state.pin.length`.
  1302→- `pinError(msg)` — Adds `.error` to all dots + shows the message, then auto-clears after 700 ms.
  1303→- `pinPress(k)` — Handles `clear` (reset), `enter` (submit), or appends a digit (max 4, auto-submits at length 4 after 160 ms).
  1304→- `submitPin()` — Marks the enter button loading, then after 700 ms either succeeds (PIN = "1234") or `pinError()`.
  1305→- Pattern: `buildPattern()` lays out a 3×3 grid of `.pattern-dot` elements positioned by canvas size; `clearPattern()` resets state + visuals + hint; `addPatternDot(idx)` pushes a unique index, marks `.active`, redraws lines, updates the count hint; `drawPatternLines()` renders an SVG `<path>` through the selected dots; `dotAt(x,y)` hit-tests pointer coords against dots (with 14 px slack); `submitPattern()` accepts ≥ 4 dots (waits 500 ms then `onAuthSuccess()`) or `patternFail()` (errors all dots + path, resets after 800 ms).
  1306→- `scanFingerprint()` — Adds `.scanning` + "Scanning…" label for 1200 ms, then `.success` + "Identity verified" for 480 ms, then `onAuthSuccess()`.
  1307→- `submitQuestion()` — Validates presence, sets the submit button loading, then after 850 ms compares the lowercased answer against `u.answer` and either `onAuthSuccess()` or `flashError()`.
  1308→
  1309→**Popover management**
  1310→- `closeAllPops()` — Removes `.open` from every popover, removes `.active` from the session button, clears `state.openPop`.
  1311→- `openPop(name, anchor)` — Closes others, marks `state.openPop`, anchors the popover above (or below if too close to top) the trigger using `requestAnimationFrame` measurements, with special bottom-right anchoring for the power popover.
  1312→- `togglePop(name, anchor)` — Closes if already open, otherwise opens.
