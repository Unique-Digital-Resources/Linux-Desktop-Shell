     1→# DMGreeter — Analysis
     2→
     3→## Overview
     4→
     5→`DMGreeter.html` is the login / display-manager (greeter) screen for the "Aether" custom Wayland display manager — the first surface a user sees before any desktop session starts. It is a single self-contained HTML document (1724 lines) loading Google Fonts (Inter + Space Grotesk) and the `lucide` icon library from a CDN, then rendering everything from one inline `<style>` block and one inline IIFE `<script>`.
     6→
     7→**Visual concept**
     8→- Dark, glassmorphic aesthetic. Surfaces use `rgba()` translucent fills layered over a blurred wallpaper (`backdrop-filter: blur(22px) saturate(120%)`).
     9→- Accent is a mint/teal (`--accent: #6ad1b3`) used for primary actions, focused fields, active tabs, session indicators, and the success overlay; text is near-white `#eef3f7`.
    10→- A fixed `.wallpaper` gradient sits behind a remote `.wallpaper-img` (Unsplash) that fades in once loaded, with a left-to-right `.veil` gradient darkening the image for legibility.
    11→- A light theme is fully supported via `[data-theme="light"]` overrides of every design token.
    12→- Motion is restrained and cubic-bezier-eased (`--ease: cubic-bezier(.22,.61,.36,1)`, `--ease-out: cubic-bezier(.16,1,.3,1)`), with a `prefers-reduced-motion` short-circuit at the bottom.
    13→
    14→**Main UI regions (top → bottom)**
    15→1. **Wallpaper layers** — `.wallpaper` (gradient fallback) + `.wallpaper-img` (remote image, fades in) + `.veil` (legibility scrim).
    16→2. **Stage** — `.stage` flex container centering the auth area.
    17→3. **Auth wrapper** — `.auth-wrapper` (column) containing:
    18→   - `.auth-container` (row): **user-box** (left, expandable drawer of avatars) + **auth-card** (right, 440 px glass card with method tabs, step indicator, and method panels for password / PIN / pattern / fingerprint / security question).
    19→   - `.statusbar` (pill-shaped, full width below the cards): session picker on the left, system indicators (network, volume, battery, theme, power) on the right.
    20→4. **Popovers** — `.popover` panels anchored above their trigger buttons for session list, network info, volume slider, and power menu.
    21→5. **Dialog + scrim** — `.scrim` + `.dialog` confirmation modal for power actions.
    22→6. **Overlay screens** — full-screen `.overlay-screen` for "Welcome back" success and the power-off "Shutting down" / "Restarting" / "Suspending" / "Locking" / "About" states.
    23→
    24→The page sets `<html data-theme="dark">` and provides a `<title>Aether — Display Manager</title>`.

   294→## CSS section index
   295→
   296→The stylesheet is grouped into eleven numbered sections by banner comments in the source. Below, every selector / group is listed with a one-line description of what it styles, organized by region.
   297→
   298→### 1. Design tokens
   299→- `:root` — All dark-theme CSS custom properties: accent ramp (`--accent`, `--accent-soft`, `--accent-strong`, `--accent-press`), surface tokens (`--surface`, `--surface-strong`, `--surface-hover`, `--surface-input`), text ramp (`--text` … `--text-faint`), hairlines & ring, error/success/warn, radii (`--r-sm/md/lg/pill`), `--pad-input`, `--blur`, durations (`--dur-fast/dur/slow`), eases, panel & float shadows.
   300→- `[data-theme="light"]` — Light-theme overrides for every color/shadow token above (deep teal accent, white surfaces, dark text, lighter shadows).
   301→
   302→### 2. Reset & base
   303→- `*` — Box-sizing reset, zero margin/padding.
   304→- `html, body` — Full height.
   305→- `body` — Inter font stack, text color, fallback background, `overflow:hidden`, antialiasing, optimized text rendering.
   306→- `button` / `input` — Inherit font/color, strip borders/background, pointer cursor for buttons, no outline on inputs.
   307→- `::selection` — Accent-soft selection highlight.
   308→- `button:focus-visible, .method-tab:focus-visible, .indicator:focus-visible, .session-indicator:focus-visible, .pin-key:focus-visible, .vol-toggle:focus-visible, .drawer-btn:focus-visible, .grid-avatar:focus-visible` — Shared keyboard focus ring (2 px accent ring, 6 px radius).
   309→- `.field input:focus, .field input:focus-visible` — Strip native input outline (field-level focus handled by container).
   310→
   311→### 3. Wallpaper & atmosphere
   312→- `.wallpaper` — Fixed full-viewport gradient fallback (radial accent glow top-left + cool blue glow bottom-right + linear gradient between `--bg-fallback-1/2`).
   313→- `.wallpaper-img` — Fixed full-viewport remote image layer; opacity 0 → 1 with `.loaded` (slow ease transition).
   314→- `.wallpaper-img.loaded` — Faded-in state.
   315→- `.veil` — Fixed legibility scrim over the wallpaper (two linear gradients: horizontal darkening + bottom-up darkening).
   316→- `[data-theme="light"] .veil` — Lighter veil gradients for the light theme.
   317→
   318→### 4. Stage layout
   319→- `.stage` — Relative layer above the wallpaper (`z-index:2`), full size, flex center, fluid padding via `clamp()`.
   320→- `.auth-wrapper` — Column flex, 16 px gap, `width:max-content`, capped at viewport.
   321→- `.auth-container` — Row flex holding the user-box and auth-card, 16 px gap.
   322→
   323→### 5. User box (left) — drawer inside, expands
   324→- `.user-box` — Glass panel (`--surface`, blur, hairline border, large radius, panel shadow) housing the avatar + (optional) drawer; width animates on drawer open.
   325→- `.user-box::before` — Inset 1 px top-highlight gradient overlay (glass sheen).
   326→- `.drawer-panel` — Hidden by default; inset dark panel with column layout, shown when `.drawer-open` is on the user-box.
   327→- `.user-box.drawer-open .drawer-panel` — Reveals the drawer (display:flex).
   328→- `.drawer-label` — Uppercase, letter-spaced, faint "Switch User" caption.
   329→- `.avatar-grid` — 3-row CSS grid with column auto-flow for the avatar buttons.
   330→- `.grid-avatar` — 44 px circular avatar button, transparent border, hover scale + accent border, `.selected` accent ring.
   331→- `.grid-avatar img` — Full-cover image fill.
   332→- `.grid-avatar:hover` — Accent border + 1.08 scale.
   333→- `.grid-avatar.selected` — Accent border + 3 px accent-soft ring.
   334→- `.user-box-content` — Fixed 220 px column, centered avatar + name + handle.
   335→- `.large-avatar` — 128 px circular cover image with hairline-strong border, drop shadow, surface-input background, bottom margin.
   336→- `.user-name` — Space Grotesk 22 px / weight 500, negative letter-spacing, centered.
   337→- `.user-handle` — 13 px muted Space Grotesk handle.
   338→- `.drawer-btn` — Absolutely-positioned 32 px circular toggle left of the box (`-16 px`), surface-strong fill, hairline-strong border, float shadow, accent-on-hover.
   339→- `.drawer-btn:hover` — Accent fill, dark text, accent border.
   340→- `[data-theme="light"] .drawer-btn:hover` — White text on accent.
   341→- `.drawer-btn svg` — 16 px, rotation transitions.
   342→- `.user-box.drawer-open .drawer-btn svg` — Rotates the chevron 180° when drawer is open.
   343→

   347→- `.method-tabs` — Pill-shaped segmented control holding the five method tabs.

   903→    }

  1256→### Bullet summary
  1257→
  1258→**Constants / data**
  1259→- `WALLPAPER_URL` — Unsplash photo URL (also referenced in the `.wallpaper-img` CSS); preloaded by an `Image()` so the `.loaded` class can fade it in.
  1260→- `DEMO` — `{ password:"demo", pin:"1234", patternMinLen:4 }` accepted credentials / pattern minimum.
  1261→- `SESSIONS` — Array of 6 desktop sessions (`hyprland`, `kde`, `gnome`, `sway`, `xfce`, `custom`); each carries `id`, `name`, `desc`, and an inline SVG `logo` used in the session popover.
  1262→- `USERS` — Array of 6 demo users (`Aria Voss`, `Kenji Sato`, `Mira Sol`, `Devon Hart`, `Yuki Tanaka`, `Sage Lin`) with pravatar.cc avatars and a per-user `auth` strategy (`password`, `pin`, `pattern`, `question`, or `multi-step`), optional `pw`, `requiresUsername`, `question`/`answer`, or a `steps[]` array.
  1263→
  1264→**State variables (single `state` object)**
  1265→- `userIndex`, `method` (current auth method), `authStatus` (`idle|loading|success`).
  1266→- `multiStep` = `{ active, current, total }` for users with chained steps.
  1267→- `session`, `theme` (`dark|light`), `openPop` (which popover is open), `drawerOpen`, `powerAction`.
  1268→- `net` = `{ name, online }`, `battery` = `{ level, charging }`, `volume` = `{ level, muted }`.
  1269→- `pin` (entered PIN string), `pattern` (selected dot-index array), `patternDrawing` (boolean).
  1270→
  1271→**Helpers**
  1272→- `$` / `$$` — scoped `querySelector` / `Array.from(querySelectorAll)`.
  1273→- `user()` / `session()` — current user / session object lookups.
  1274→- `refreshIcons()` — re-runs `lucide.createIcons()` after dynamic `<i data-lucide>` insertions.
  1275→- `swapIcon(el, name)` — Replaces an existing icon element (svg or `[data-lucide]`) with a new `<i data-lucide="…">`, preserving non-`lucide` classes, then `refreshIcons()`.
  1276→
  1277→**Render functions**
  1278→- `renderIdentity()` — Sets the avatar `src` (with `onerror` fallback gradient), `#userName`, `#userHandle`.
  1279→- `renderSession()` — Updates `#sessionVal` and toggles `.selected` + check opacity on the session list items.
  1280→- `renderVolume()` — Picks `volume-x`/`volume-1`/`volume-2` icon, swaps it on both `#volBtn` and `#volToggle`, updates `#volText`/`#volTip`/`#volSlider`/`#volValue`, toggles `.muted` on the toggle.
  1281→- `renderBattery()` — Sets `#batFill` width, `#batText`, and `#batTip` (charging vs remaining).
  1282→- `renderNetwork()` — Sets `#netText` to the SSID.
  1283→- `renderAll()` — Calls all five renderers in order.
  1284→
  1285→**Auth flow control**
  1286→- `updateAuthChrome()` — Detects `multi-step` users, hides/shows method tabs vs step indicator, toggles the username sub-input (`requiresUsername`), swaps the password field's lead icon (`user-round` vs `lock`), then `renderStep()` or `setMethod(u.auth)`, then `updateDemoHints()`.
  1287→- `setMethod(m)` — Sets `state.method`, toggles `.active` on the matching tab and panel, calls `clearErrors()`, and (for pattern) schedules `buildPattern()` after 50 ms.
  1288→- `clearErrors()` — Strips `.error`/`.show` from every field, error message, and pin dots.
  1289→- `stepLabel(type)` — Maps a step type to a display label.
  1290→- `renderStep()` — Updates `#stepLabel` ("Step X of Y · Type") and rebuilds `#stepDots` (active + completed dots), then `setMethod(step.type)` + `updateDemoHints()`.
  1291→- `advanceStep()` — Resets the just-completed step's input (password/PIN/pattern/question), increments `multiStep.current`, and `renderStep()`.
  1292→- `onAuthSuccess()` — Either `advanceStep()` (after a 450 ms delay) when more steps remain, or `showSuccess()` for the final success.
  1293→- `updateDemoHints()` — Writes the demo hint for every method (`demo: …`), and either shows the user's `question`/`answer` in `#questionText`/`#qHint` or a "no question set" fallback.
  1294→- `setBtnLoading(btn, on)` — Toggles `.loading` + `disabled` on a primary button and sets `state.authStatus` accordingly.
  1295→- `showSuccess()` — Fills `#successTitle`/`#successSub`/`#successIcon` and adds `.show` to the success overlay.
  1296→- `returnToGreeter()` — Removes `.show` from both overlays, resets `authStatus`/`multiStep.current`, re-renders the current step if multi-step, clears every input + pin + pattern + errors.
  1297→- `flashError(fieldEl, msgEl, msg)` — Adds `.error` to the field, sets the message text + `.show`, then strips `.error` after 420 ms.
  1298→
  1299→**Per-method handlers**
  1300→- `submitPassword(e)` — Validates username (if required) and password presence, sets the submit button loading, then after 850 ms compares against the user's `pw` (or the step's `pw` if multi-step) and either calls `onAuthSuccess()` or `flashError()`.
  1301→- `renderPin()` — Toggles `.filled` on the four pin dots based on `state.pin.length`.
  1302→- `pinError(msg)` — Adds `.error` to all dots + shows the message, then auto-clears after 700 ms.
  1303→- `pinPress(k)` — Handles `clear` (reset), `enter` (submit), or appends a digit (max 4, auto-submits at length 4 after 160 ms).
  1304→- `submitPin()` — Marks the enter button loading, then after 700 ms either succeeds (PIN = "1234") or `pinError()`.
  1305→- Pattern: `buildPattern()` lays out a 3×3 grid of `.pattern-dot` elements positioned by canvas size; `clearPattern()` resets state + visuals + hint; `addPatternDot(idx)` pushes a unique index, marks `.active`, redraws lines, updates the count hint; `drawPatternLines()` renders an SVG `<path>` through the selected dots; `dotAt(x,y)` hit-tests pointer coords against dots (with 14 px slack); `submitPattern()` accepts ≥ 4 dots (waits 500 ms then `onAuthSuccess()`) or `patternFail()` (errors all dots + path, resets after 800 ms).
  1306→- `scanFingerprint()` — Adds `.scanning` + "Scanning…" label for 1200 ms, then `.success` + "Identity verified" for 480 ms, then `onAuthSuccess()`.
  1307→- `submitQuestion()` — Validates presence, sets the submit button loading, then after 850 ms compares the lowercased answer against `u.answer` and either `onAuthSuccess()` or `flashError()`.
  1308→
  1309→**Popover management**
  1310→- `closeAllPops()` — Removes `.open` from every popover, removes `.active` from the session button, clears `state.openPop`.
  1311→- `openPop(name, anchor)` — Closes others, marks `state.openPop`, anchors the popover above (or below if too close to top) the trigger using `requestAnimationFrame` measurements, with special bottom-right anchoring for the power popover.
  1312→- `togglePop(name, anchor)` — Closes if already open, otherwise opens.
  1313→
  1314→**Drawer / user switching**
  1315→- `buildAvatarGrid()` — Renders one `.grid-avatar` button per user (with `onerror` gradient fallback), `.selected` on the current user, click → `selectUser(i)` + `closeDrawer()`.
  1316→- `openDrawer()` / `closeDrawer()` / `toggleDrawer()` — Toggles `.drawer-open` on `#userBox`.
  1317→- `selectUser(index)` — Resets `userIndex` + all inputs + pin + pattern + errors, re-renders identity + auth chrome + avatar grid, closes popovers, and focuses the appropriate input after 200 ms.
  1318→
  1319→**Session list**
  1320→- `buildSessionList()` — Builds one `.pop-item` per session with logo + name + desc + check icon, click → updates `state.session`, `renderSession()`, `closeAllPops()`.
  1321→
  1322→**Dialog / power**
  1323→- `openDialog(action)` — Looks up title/body/confirm-label/icon for `shutdown`/`restart`/`suspend`, sets `state.powerAction`, recolors `#dlgIcon`/`#dlgConfirm` (danger vs primary), closes popovers, opens scrim + dialog.
  1324→- `closeDialog()` — Removes `.open` from scrim + dialog, clears `state.powerAction`.
  1325→- `confirmPower()` — Closes the dialog, sets `#powerTitle`/`#powerSub`/`#powerIcon` for the chosen action, and shows the power overlay.
  1326→
  1327→**Theme**
  1328→- `setTheme(t)` — Sets `state.theme`, toggles `data-theme` on `<html>`, swaps the theme button icon (`sun-moon` for dark, `sun` for light).

  1330→**Event wiring (`wire()`)**
